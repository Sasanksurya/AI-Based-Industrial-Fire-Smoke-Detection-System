# 🔥 AI-Based Industrial Fire & Smoke Detection System

## 📌 Project Overview

This project is a real-time AI-powered Industrial Fire and Smoke Detection System built using YOLOv8, OpenCV, Streamlit, Email Alerts, and Telegram Alerts.

The system continuously monitors live webcam footage and detects fire or smoke in real time. When detection occurs, the system:

- Captures incident screenshots
- Sends Email Alerts
- Sends Telegram Alerts
- Displays live monitoring dashboard
- Stores incident history
